## 구간 배분

1분 강좌 — 무음 구간(B롤 2초 + 스팅어 3초)을 제외한 내레이션 약 260자.

| 구간 id | 내레이션 | 화면 | 길이 | 글자수 | 비고 |
|---|---|---|---|---|---|
| broll | 없음 | 실사 B롤 | 2.0s | 0 | 반죽을 치대는 장면 — 1회차 유일 실사 |
| title | 도입 | course-intro.html | 4.0s | ~30 | "반죽은 밀가루에 물이 들어가며 시작합니다" |
| hook | 훅 | shape/도식 | 3.5s | ~40 | "밀가루와 물, 섞는 순간 무언가가 일어납니다" |
| stinger | 없음 | course-stinger.html | 3.0s | 0 | 강좌 시그니처 — 회차마다 동일 |
| ch1 | 약속 + 본론 1 | chapter.html | 15.0s | ~130 | 물과 글루텐 단백질의 상호작용 |
| s1 | 본론 2 | 도식 | 12.0s | ~60 | 치대기로 단백질 네트워크 형성 |
| outro | 마무리 | outro.html | 5.0s | ~20 | "반죽은 이렇게, 물과 글루텐의 만남으로 완성됩니다" |
| | | | **합계 44.5s** | **~260자** | 클립 여유 + 무음(BGM) ≈ 60s |

## 도식으로 만들 것

구조·흐름·비교·시간에 따른 변화를 말하는 구간이다. 글자 카드로 두면 안 되는 자리.

| 구간 | 그림이 져야 할 설명 | 템플릿 |
|---|---|---|
| hook | 반죽 되는 장면의 반전 (밀가루+물 → 탄력 있는 반죽) | 공용 shape/도식 |
| ch1 | 물 분자와 글루텐 단백질의 수화 (흡수) | chapter.html |
| s1 | 치대기로 단백질이 엮이는 네트워크 형성 | 공용 motion (신규 제작 금지) |

## 대본 스켈레톤

```
[Title] 반죽은 밀가루에 물이 들어가며 시작합니다.

[Hook] 밀가루와 물, 간단하지만 섞는 순간부터 탄력 있는 반죽으로 변해갑니다.

[Promise] 물이 밀가루 단백질에 스며드는 것, 치대기가 단백질을 엮는 것 — 이 두 순간을 봅시다.

[Ch1] 밀가루는 주로 단백질 두 종류로 이뤄져 있습니다. 물을 만나면 이 단백질이 흡수하고 
구조를 갖추기 시작해요.

[S1] 치대기는 이 단백질을 늘이고 꼬아, 서로를 엮습니다. 엮일수록 반죽이 탄력을 얻고 
늘어날 수 있게 되는 거죠.

[Outro] 반죽은 이렇게, 물과 글루텐의 만남으로 완성됩니다.
```

## 재미 장치

- **반문**: "그런데 왜 물을 만나면 달라질까요?" → 본론이 답
- **회수**: 훅의 "무언가가 일어납니다" → ch1에서 "단백질이 흡수" → s1에서 "엮인다"로 명확화
- **구체적 장면**: "밀가루와 물, 섞는 순간" — 추상 대신 눈에 띄는 장면

## 대상별 입장권

회차는 독립. 앞 강 참조 금지. 배경 지식 필요하면 promise에서 한 문장으로 세운다:
"글루텐은 밀가루 단백질이 물을 만나 만들어지는 네트워크입니다."
