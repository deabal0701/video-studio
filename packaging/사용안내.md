# Video Studio 사용 안내

강좌 영상을 **화면만으로** 만드는 프로그램입니다. 대본을 쓰고 버튼을 누르면 음성 합성 →
화면 렌더 → 합성까지 자동으로 돌아가고, 검수 프레임과 유튜브 업로드 준비물까지 나옵니다.

---

## 1. 설치

`VideoStudioSetup.exe` 를 실행합니다. **관리자 권한이 필요 없습니다** — 내 계정 폴더에만 설치됩니다.

> Windows 가 "PC를 보호했습니다" 창을 띄우면 **추가 정보 → 실행**을 누르세요.
> (배포자가 코드 서명 인증서를 붙이기 전까지 나타나는 경고입니다.)

설치 후 바탕화면의 **Video Studio** 를 실행합니다. 다른 프로그램을 미리 깔 필요는 없습니다 —
영상 제작에 쓰는 부품(Node·ffmpeg·Chromium)이 프로그램 안에 들어 있습니다.

## 2. 첫 실행 — 4단계 안내

처음 한 번만 나오는 창입니다. **전부 건너뛰어도 프로그램은 정상 동작합니다.**

| 단계 | 내용 |
|---|---|
| 1 데이터 폴더 | 강좌·회차 파일이 저장될 곳. **이 폴더가 원본이니 백업 대상으로 잡으세요.** 기본값 그대로 두면 됩니다 |
| 2 자가진단 | 부품이 제대로 들어왔는지 점검. 전부 OK 면 그대로 다음 |
| 3 키 (선택) | 유료 음성·AI 기능을 쓸 때만. 없으면 **무료 음성(edge)** 으로 동작하고 AI 버튼만 꺼집니다 |
| 4 소재 (선택) | 배경음악·영상 소재. 저작권 문제로 프로그램에 넣지 못해 원 제공처에서 직접 받습니다 |

## 3. 영상 한 편 만들기

```
① 강좌 만들기 → ② 회차 만들기 → ③ 대본 쓰기 → ④ 빌드 → ⑤ 검수 → ⑥ 배포 준비물
```

1. **[+ 새 강좌]** — 강좌명·태그라인·목소리·색을 정합니다. **한 번 정하면 모든 회차가 물려받습니다.**
   목소리는 [▶ 미리듣기] 로 실제 소리를 듣고 고르세요.
2. **② 커리큘럼** 탭에서 **[회차 생성]** — 회차 폴더와 대본 골격이 자동으로 만들어집니다.
3. **⑤ 대본** 탭 — 왼쪽에서 클립을 고르고 가운데에 내레이션을 씁니다.
   - 화면(도식·B롤)은 **[템플릿 선택…] / [B롤 선택…]** 버튼으로만 고릅니다 (경로를 직접 쓰지 않습니다)
   - 오른쪽 프리뷰가 **실제 결과와 같습니다** — 슬라이더로 시간을 옮겨 보세요
   - 왼쪽 아래 게이지가 **빨강**이면 분량 초과입니다. 줄이지 말고 **회차를 나누세요**
   - 빨간 경고가 뜨면 그 자리에서 고칩니다 (틀린 채로 구우면 수십 분을 버립니다)
4. **[빌드]** — 진행이 로그로 흐릅니다. 5분짜리 한 편에 **5분 안팎** 걸립니다.
5. **⑥ 검수** 탭 — 완성본 재생 + 검수 프레임 5장 + 자막 대조. 체크박스로 확인 기록을 남깁니다.
6. **⑦ 배포** 탭 — 제목·설명·챕터가 자동 생성됩니다. [복사] 로 유튜브에 붙여 넣으세요.

## 4. 알아두면 좋은 것

- **파일이 원본입니다.** 데이터 폴더의 `projects\<회차id>\` 안 파일이 정본이고, 완성본은
  언제든 다시 구울 수 있는 결과물입니다. 백업은 `projects\` 만 하면 됩니다.
- **빌드는 동시에 2편까지** 돕니다. 같은 회차를 동시에 굽지는 못합니다.
- **작업 큐**(왼쪽 메뉴)에서 진행 중인 빌드를 볼 수 있고, 화면 아래 상태 표시줄에도 뜹니다.
- 프로그램 밖에서 파일을 고쳐도 됩니다 — 다시 열면 그대로 반영됩니다.

## 5. 문제가 생기면

| 증상 | 확인 |
|---|---|
| 빌드가 바로 실패 | **설정 → 자가진단 → [다시 점검]** 에서 빨간 항목 확인 |
| 음성이 안 만들어짐 | **[TTS 연결 확인]** — 인터넷 연결이 필요합니다 |
| AI 버튼이 회색 | 키가 없어서입니다 (**설정 → 키**). 없어도 나머지는 다 됩니다 |
| 화면이 검게 나옴 | ⑤ 대본에서 빨간 경고를 확인하세요 — 대개 소재 경로 문제입니다 |
| 저장할 때 "파일이 밖에서 바뀌었습니다" | 다른 프로그램이 같은 파일을 고쳤습니다. 새로 열어 다시 편집하세요 |

## 6. 업데이트 · 제거

- **업데이트**: 새 `VideoStudioSetup.exe` 를 그냥 실행하면 덮어씁니다.
  **작업 파일(projects·완성본)은 그대로 남습니다** — 데이터 폴더가 따로이기 때문입니다.
- **제거**: 설정 → 앱에서 제거. 데이터 폴더는 **지워지지 않습니다**(직접 지우셔야 합니다).
  단, 받아 둔 소재는 프로그램과 함께 지워집니다 — 다시 받으면 됩니다.
