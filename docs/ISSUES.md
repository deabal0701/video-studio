# 이슈 대장

실측에서 나온 결함·한계를 한곳에 모은다. **재현 방법과 근거(어디서 어떻게 드러났나)를 함께
적는다** — 나중에 읽는 사람이 "정말 문제인가"를 다시 판단할 수 있어야 한다.

- 상태: `열림` · `수정됨` · `보류`(결정 대기) · `기각`
- 화면·UX 다듬기 순회 기록은 [11_polish-loop](design/11_polish-loop.md), 구현 진행은
  [BUILD_LOOP](BUILD_LOOP.md) 이 정본이다. 여기는 **아직 안 고쳤거나 방금 고친 결함**의 목록이다.

## 수정됨 (2026-08-23)

| # | 제목 | 원인 | 고친 방법 |
|---|---|---|---|
| F-1 | 배포본에서 AI 버튼이 켜졌다가 실패 | claude 경로가 Claude Code CLI 를 필요로 하는데 설치본에 없었다 | **D18 — 순수 HTTP 전환.** CLI·SDK 의존 제거, 키 하나로 동작 |
| F-2 | 단발 영상이 **무음**으로 나온다 | 단발 골격은 내레이션이 최상위 `scenes[]` 에 있어 카드에 `narration` 키가 없다. 러너가 그 부재를 "말하지 않는 구간"으로 읽었다 | 말할 자리가 하나도 없으면 카드에 내레이션을 단다 (`_may_speak`) |
| F-3 | 단발 클립 5개 중 4개가 **조용히 사라진다** | `compose.js` 는 `before` 가 가리키는 씬이 없으면 클립을 오류 없이 버린다. 스캐폴딩이 녹화 씬을 지우면서 `before:"s1"` 을 그대로 뒀다 | `_trim_clips` 가 남은 클립을 전부 `"end"` 로 옮긴다. [02_data-model](design/02_data-model.md) 에 함정 기록 |
| F-4 | 요청 길이를 크게 넘긴다 (10초 → 15.4초) | 예산이 프롬프트에만 있고 검증이 없었다 | 예산 초과를 되먹임 항목에 추가 (`BUDGET_SLACK` 1.25) |
| F-5 | B롤 미선택으로 빌드가 막힌다 | 모델이 소재 목록에서 고르지 않았고, 되먹임 대상도 아니었다 | 되먹임 + 그래도 비면 임시 선택 후 **무엇을 넣었는지 고지** |
| F-6 | 모델이 **경로를 지어낸다** (`title.src`) | 경로형 params 를 모델 기입 대상에 열어 뒀다. 틀려도 오류가 아니라 배경만 빠진다 | `PATH_PARAMS`(src·fontUrl) 제외 → `_title_bg` 가 실물 프레임을 뽑아 정확한 상대경로 기입 |
| F-7 | 되먹임 뒤 남은 `[자리표시자]` 가 TTS 로 읽히거나 빌드를 막는다 | 최종 방어가 없었다 | 지어내지 않고 **비우고 고지** |
| F-8 | **AI 도식 색이 프로젝트와 어긋난다** | ① 발췌가 `authoring.md` 경로 규칙 소절을 잘라 먹었다 ② 역할 선언이 "같은 폴더 상대경로"라는 틀린 안내를 했다 ③ 팔레트를 넘긴 적이 없다 → 링크가 깨져 `_base.css` 가 안 걸리고 모델 자기 색만 남았다 | 빠진 절 포함 + `_fix_shared_links` 가 경로를 계산해 기입 + `diagram_rules(palette)` |
| F-10 | **외부 앱 화면 녹화가 앱에서 도달 불가** (구 I-2) | 엔진은 녹화를 지원하는데 ① 스캐폴딩이 단발 종류의 녹화 씬을 걷어내고 ② 에디터에 `scenes[]` 가 없고 ③ AI 도 안 썼다 | `course.capture.baseUrl` 신설(위저드 **앱 주소** 칸) → 주소가 있으면 스캐폴딩이 녹화 씬을 살린다. **신규 `engine/probe.js`** 가 실제 페이지를 훑어 조작 가능한 요소(글자·selector·네이티브 CSS 경로)를 뽑고, AI 는 **그 목록에서만** 골라 녹화 대본을 쓴다(셀렉터를 지어내면 조용히 건너뛴다). 액션 변환은 결정적 |
| F-11 | 녹화 자격증명 보관 자리가 없다 (구 I-5) | `type` 액션이 리터럴만 받아 대본에 비밀번호를 박아야 했다 | **비밀번호를 아예 안 쓴다** — probe 가 로그인 후 세션을 `storageState` 로 저장하고 녹화가 그대로 이어받는다(record.js 187행). 대본엔 `.env` **이름만**, 값은 빌드 직전에만 임시로 풀린다. 세션은 빌드마다 새로 딴다(만료 대비) |
| F-12 | `highlight` 가 빌드를 죽인다 | `highlight` 만 브라우저 네이티브 `querySelector` 로 도는데 Playwright 전용 `:has-text()` 를 주면 "not a valid selector" 로 녹화가 중단된다 | probe 가 네이티브 CSS 경로도 함께 뽑아 번역. 셀렉터 기반 액션은 `optional` 로 — 화면이 조금 달라져도 촬영이 안 끊긴다 |
| F-13 | 로그인 판정이 일러 세션을 못 딴다 | SPA 가 로그인 직후에도 `/login?redirect=…` 를 잠시 들고 있어 고정 대기(2.5초) 판정이 **성공한 로그인을 실패로** 읽었다 | 주소가 로그인 화면을 벗어날 때까지 대기 + **경로를 다 돌아본 뒤** 최종 판정 |
| F-14 | 스크롤이 화면을 안 움직인다 | 모델이 "3"(세 번쯤)처럼 양이 아니라 정도로 답하는데 3px 을 굴려 정지 사진처럼 찍혔다 | 작은 값은 화면 단위로 읽는다(×320px, 부호 유지) |
| F-9 | 대시보드 카드 높이가 들쭉날쭉 | 단발 카드에서 진행바를 빼서 행 수가 달랐다 | 회색 바로 행 구성을 맞춤 (5종 실측 120px 일치) |

## 기록 규약

새 이슈는 **열림** 표에 추가하고, 고치면 **수정됨** 으로 옮기며 원인·해결을 한 줄로 남긴다.
