# 06 — 로드맵 · 상용화 트랙 · 리스크

## 단계 로드맵 (로컬 제품)

각 단계는 **그 자체로 쓸모 있는 상태**에서 끝난다. 수용 기준을 채워야 다음 단계.

### 0단계 — 저장소 스캐폴딩 (반나절~1일)

| 작업 | 비고 |
|---|---|
| 신규 저장소 생성 + README 의 카피 목록 실행 | engine 은 **스킬 scripts/ 에서** (tools/video 는 구본 — preflight 없음) |
| engine 셀프테스트 통과 | `check-tts` + `scenes.selftest.json` 빌드 → mp4 2개 |
| fixtures 회차 1편 재현 빌드 | hr-basics-01 이 새 저장소에서 그대로 구워지는가 — **경로·폰트 이전 검증이 여기서 끝난다** (fontUrl 이 h5-saas 내부를 가리키던 것을 engine/fonts 로 교체) |
| `inspect.js` 작성 | preflight·templateKeys·ffprobe 를 JSON 출력으로 묶는 유일한 신규 엔진 파일 |
| Python 환경 + pyproject + core 뼈대 + 테스트 러너 | |

**수용**: 새 저장소 단독으로(h5-saas 없이) 픽스처 회차 빌드 성공.

### 1단계 — 읽기 전용 콘솔 (1~2주)

core: storage(LocalFS)·indexer·engine_io·jobs(빌드만). api: 조회 전부 + build + SSE.
web: 대시보드·강좌/회차 목록·scenes 뷰어(편집 없음)·빌드 버튼+진행·프레임 그리드·mp4 재생.

**수용**: 화면에서 픽스처 회차를 빌드하고 프레임 4종을 보고 mp4 를 재생한다.
**의도**: 데이터 모델·stdout 파서·SSE — 위험한 가정 전부를 편집 기능 없이 검증.

### 2단계 — 강좌 편집 (2주)

경로 계산기(`paths.py` — **테스트 최우선**, [02](02_data-model.md)의 실측 5행이 케이스) ·
schema 라운드트립(`_` 보존) · If-Match. 화면 ①③ + 회차 스캐폴딩(②의 생성 버튼) +
미디어 라이브러리 + TTS 미리듣기 + 일관성 대조.

**수용**: 화면만으로 새 강좌 개설 → 회차 생성 → (대본은 파일로 편집) → 빌드까지.
라운드트립 무손실: 기존 픽스처를 열고 저장했을 때 diff 0.

### 3단계 — 대본 에디터 (3~4주 · 본체)

화면 ④⑤⑥⑦ 완성: 구성표+예산 게이지 · 클립 에디터(params 자동 폼·피커·B롤 길이 검사·
발화시각 계산기·타이틀 프레임 버튼) · 프리뷰(iframe 스크럽) · 부분 TTS · 검수 자동화
(프레임·무음·자막 대조·체크리스트) · 배포 산출물 자동 생성.

**수용**: **새 회차 한 편을 코드·에디터 없이 화면만으로 완성** (대본→빌드→검수→유튜브 준비물).
그 과정에서 경로·params·분량 결함이 입력 시점에 잡히는 것을 확인.

### 4단계 — 에이전트 (2주)

[05_agent.md](05_agent.md) A(초안)·B(도식)·C(평가) + 사용량 미터. 키 없으면 비활성.

**수용**: "AI 초안 → 화면 손질 → 빌드 → AI 평가" 동선 완주. 1~3단계 기능이 키 없이 전부 동작함을 재확인.

## 상용화 트랙 (로컬 4단계 완성 후 — 병행 가능)

| 순서 | 작업 | 핵심 |
|---|---|---|
| S1 | storage S3 구현 + 렌더 워커 컨테이너화 (Node+Chromium+ffmpeg 이미지) | D8·D9 를 지켰다면 구현 교체일 뿐. 워커는 잡을 받아 프로젝트를 로컬 캐시로 내려 빌드 후 out/ 업로드 |
| S2 | 인증 + 테넌트 (프로젝트 루트 = tenant prefix) + 요금제·크레딧 (렌더 분·AI 토큰 미터) | |
| S3 | 랜딩·온보딩 위저드·관리자 콘솔 | |
| S4 | 정식 TTS 계약 (아래 리스크) · 폰트·소재 정비 | **베타 공개 전 필수** |

## ★ 상용화 리스크 — 지금 알아야 하는 것

| # | 리스크 | 내용 | 대응 |
|---|---|---|---|
| R1 | **edge TTS 약관** | 기본 TTS(edge)는 Edge 읽어주기 엔드포인트 — 무료·키 불요지만 **상용 서비스가 쓸 정식 계약이 아니다.** 스킬 자신도 azure 를 "정식 계약이 필요한 납품본"용으로 구분 | 로컬·개발은 edge 유지. **상용 베타 전 Azure Speech 계약 전환** (엔진이 이미 azure 지원 — 키만) |
| R2 | **자막 폰트** | 기본 subtitleFont "Malgun Gothic"은 Windows 동봉 폰트 — 서버 렌더 재배포 불가 | 기본값을 Pretendard(SIL OFL — 재배포·상용 가능)로 교체. 0단계에서 engine/fonts 동봉과 함께 처리 |
| R3 | **스톡 소재 재배포** | Mixkit/Pexels 등은 "영상에 사용"은 허용, **소재 파일 재배포는 금지** — 서비스가 공용 라이브러리로 소재를 제공하면 재배포에 해당할 소지 | 로컬: 사용자가 직접 받기(fetch 도구 유지). 상용: 라이선스 검토 후 정식 스톡 API 계약 또는 사용자 업로드 전용 + 라이선스 필드 필수 |
| R4 | **에이전트 비용 폭주** | 루프형 에이전트가 셀렉터 하나로 조용히 재시도 반복 (video-agent README 실증 경고) | maxTurns·지출 상한·잡 취소·사용량 미터 (4단계 내장) |
| R5 | **렌더 부하** | 편당 Chromium+ffmpeg 수십 분 — 다중 사용자면 즉시 병목 | 처음부터 잡 큐(D8) → 워커 수평 확장. 요금제에 렌더 분 포함 |
| R6 | **BGM 수익화** | mixkit 등 무료 BGM 의 유튜브 수익화 조건 상이 | 라이브러리 라이선스 필드 + 상용은 계약 음원 |
| R7 | 엔진·스킬 사본 드리프트 | h5-saas 쪽 스킬이 계속 진화하면 새 저장소와 갈라짐 | ENGINE_VERSION.md 동기화 기록 ([01](01_architecture.md)). 신규 저장소가 자리 잡으면 **정본을 새 저장소로 옮기고 h5-saas 쪽을 참조로 격하**하는 시점을 정한다 |

## 테스트 전략

| 대상 | 방법 |
|---|---|
| `paths.py` 경로 계산 | **최우선 단위 테스트** — 실측 5행 + 역산 라운드트립 |
| schema 라운드트립 | 픽스처 전 대본을 load→save → diff 0 (주석·키순서 보존) |
| validate (예산·일관성·B롤 길이) | 픽스처 변형 케이스 |
| engine_io stdout 파서 | 실제 빌드 로그 캡처를 픽스처로 |
| E2E | 셀프테스트 대본 빌드를 CI 에서 (Playwright·ffmpeg 필요 — 셀프호스트 러너 or 컨테이너) |
| web | 대본 에디터 스토어(클립 CRUD·예산 계산) 위주. E2E 는 3단계 수용 기준 시나리오 1본 |

## 이 설계서의 유지

이 폴더가 새 저장소 `docs/design/` 으로 이동한 뒤에는 **새 저장소 쪽이 정본**이다.
구현하며 어긋나는 결정이 나오면 설계서를 고치고, 큰 방향 변경은 00_overview 의 결정 표에
날짜와 함께 추가한다 (h5-saas 의 AGENTS.md "노선 이력" 방식을 따른다).
