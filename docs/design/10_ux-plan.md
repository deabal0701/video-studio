# 10 — UX 재설계 계획 (2026-08-22 사용자 지적 9건)

> **발단**: "화면이 복잡해서 어떻게 영상을 만들어야 할지 모르겠다." 지적 9건을 받아
> 타 도구를 조사하고 재설계한다. **기능 제거 없음** — 사용자 조건. 상태: 🟡 계획 확정, 구현 중.

## 조사 — 단순한 영상 도구들은 어떻게 하나

| 도구 | 흐름 | 배울 것 |
|---|---|---|
| Pictory · InVideo · Canva | **주제 입력 → AI 대본 → 다듬기 → 출력** 한 줄 | AI 대본이 흐름의 **맨 앞**이다 — 우리는 보드 카드 구석에 숨어 있다 |
| 공통 (NN/g 점진적 노출) | 기본 옵션만 보이고 고급은 요청 시. **2단계 초과 금지** | 위저드가 8필드를 한 번에 묻는 것이 문제. 필수는 이름·종류뿐 |
| CapCut 류 편집기 | 목록(좌) · 미리보기(중) · 속성(우) + 큰 [내보내기] 하나 | ⑤ 대본 3열 구도는 이미 이 문법 — 문제는 용어다 |

## 새 정보 구조 — 번호의 재정의

**진단**: ①②③(프로젝트)과 ④⑤⑥⑦(영상)이 하나의 번호 체계처럼 보이는데,
①②③은 **순서가 아니다**(설정·목록·킷은 단계가 아님). 순서인 것은 영상 안의 4단계뿐.

```
대시보드
└─ 프로젝트         [영상 목록]  [설정]  [브랜드 킷]     ← 번호 없음 (순서 아님)
   └─ 영상          ① 구성  ② 대본  ③ 검수  ④ 배포      ← 번호는 여기만 (진짜 순서)
```

- 프로젝트 탭: **영상 목록이 첫 탭·기본 탭** (주인공), 번호 제거
- 영상 탭: ④⑤⑥⑦ → **①②③④ 재부여** — "①부터 하면 된다"가 화면에서 읽힌다

## 지적 9건 — 진단과 결정

| # | 지적 | 진단 | 결정 |
|---|---|---|---|
| 1 | 설정의 "저장"이 뭘 저장하나 | 버튼이 대상을 안 말함 | **"키 저장"** 으로. 저장 결과는 버튼 옆에 즉시 표시 |
| 2 | "다시 점검"·"TTS 연결 확인"이 뭔가 | 개발자 용어 | 섹션을 **"환경 점검 — 영상을 만들 준비가 됐는지 확인합니다"** 로. 버튼: "다시 점검"(유지 — 설명이 생기면 자명), "목소리 합성 테스트 (한 문장을 실제로 만들어 봅니다)" |
| 3a | "이기고 있습니다"가 무슨 말 | 은어 | **"~에 설정돼 있어 그 값이 우선 적용됩니다 — 여기서 바꾸려면 그 파일에서 지우세요"** |
| 3b | 점검이 OK·OK·OK **체크되는 동작**으로 보이면 | 결과만 한꺼번에 뜸 | 진단을 **항목별 순차 표시** — 줄이 하나씩 나타나며 OK 가 찍힌다 (기다림이 신뢰가 된다) |
| 4a | 위저드 창을 크게 | 520px 고정 | **720px** |
| 4b | 프로젝트 id 꼭 필요한가 — 이름만 쓰면 자동 생성 | id 는 폴더명(필수)이지만 사용자가 지을 필요는 없다 | **이름만 필수. id 는 자동 생성**(종류+날짜+순번, 예: `promo-0822a`) + "고급" 접기에서 직접 지정 가능 |
| 4c | hr-basics 예시 바꿔라 | 다른 프로젝트의 이름 | 예: `summer-promo` |
| 4d | 목소리를 왜 여기서? 설정에도 있는데 차이는 | 같은 값의 초기값/수정처 관계인데 화면이 설명 안 함 | 위저드에서 **"기본 설정" 접기로 이동** — 펼치지 않으면 종류 기본값. 안내문: "만든 뒤 [설정] 탭에서 언제든 바꿀 수 있습니다" |
| 4e | 색을 청·주황·검정·초록 4개 선택 + 필요시 추가 | 색 3칸이 뭘 뜻하는지 모름 | **팔레트 프리셋 4종 스와치**(청·주황·초록·검정 — 전부 WCAG 4.5:1 검증) 원클릭 + [직접 고르기…] 는 접기 안에 |
| 4f | 영상 길이 콤보 1·5·10·15분 + 직접 입력 | 자유 텍스트라 형식을 모름 | **편집 가능한 콤보** — 1분·5분·10분·15분 + 직접 입력 |
| 4g | BGM 은 나중에 설정하면 되지 않나 | 맞음 | 위저드에서 **제거** — [설정] 탭에서. 기본 BGM 자동 |
| 5 | 프로젝트 설정 수정은 어디서 | [← 프로젝트] → 설정 탭인데 발견 안 됨 | 탭 재배치(위 IA)로 해결 + 영상 화면 머리에 프로젝트명 표시(9번과 함께) |
| 6 | 설정·영상 목록·브랜드 킷 순서가 안 직관적 | 번호가 순서를 사칭 | **[영상 목록] [설정] [브랜드 킷]** — 번호 제거 (위 IA) |
| 7 | 대본은 어떻게? 빌드하면 생기나? 쉽게 만들 방법은? | **빌드는 대본→영상**이지 대본을 만들지 않는다. AI 초안이 보드 카드에만 숨어 있음 | ② 대본 탭에 **빈 상태 안내 + 시작 3버튼**: [AI 로 대본 쓰기] · [글 붙여넣기 → AI 가 배분] · [직접 쓰기]. 관계를 문장으로: "대본을 쓰면 [빌드] 가 영상으로 만듭니다" |
| 8 | broll·hook·ch2 가 뭔지 모르겠다 | 엔진 클립 id 를 그대로 노출 | **역할 한국어 라벨** 상시 표시, id 는 보조: 실사 도입(broll)·타이틀(title)·도입 훅(hook)·로고 전환(stinger)·오늘의 약속(promise)·챕터 N(chN)·본문 N(sN)·정리(recap)·마무리(outro) |
| 9 | hr-basic3-01 이 테스트강좌랑 무슨 관계? | 영상 화면 제목이 **폴더 id** | 제목을 **"테스트강좌 — 1편"**(프로젝트명·편 번호·영상 제목) 으로, id 는 캡션으로 강등 |

## 구현 단계

**P0 — 용어·구조 (즉시)**
1. 설정 화면: "키 저장"·환경 점검 문구·"우선 적용" 문구·순차 점검 표시 (#1·2·3)
2. 위저드 재구성: 720px·이름만 필수·id 자동·프리셋 팔레트 4종·길이 콤보·BGM 제거·"기본 설정" 접기 (#4)
3. 탭 IA: 프로젝트 탭 무번호 재배치·영상 탭 ①~④ (#5·6)
4. 영상 머리: "프로젝트명 — N편 제목" (#9)
5. 클립 역할 라벨 (#8)

**P1 — 대본 진입로 (#7)**
6. ② 대본 빈 상태 + [AI 로 대본 쓰기]/[글 붙여넣기]/[직접 쓰기]
7. 붙여넣은 글을 AI 가 클립에 배분 (agent draft 에 원문 전달)

**P2 — 흐름 안내**
8. 영상 탭 하단 "다음: ② 대본 쓰기 →" 상시 버튼
9. 태그라인 미입력 시 대괄호 안내문이 값이 되는 결함 차단

수용 기준: 처음 온 사람이 안내 없이 **"만들기 → (AI) 대본 → 빌드 → 재생"** 을 스스로
찾아가고, 화면의 모든 문구가 담당자 언어다(파일명·id·은어 0건 — 09 G6·G7 확장).
