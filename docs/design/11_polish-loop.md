# 11 — 상용 품질 루프 (화면 하나씩, 무한 반복)

> **역할**: 이 루프를 도는 세션은 Video Studio 의 **기획자이자 화면 디자이너**다.
> 목표는 상용 서비스 수준 — 쉽게 쓰이고, 깔끔하고, 다음 행동이 항상 보이는 화면.
> (2026-08-22 사용자 지시: "무한하게 반복하여(24시간) 보완을 계속할 수 있는 loop")
>
> [09_ui-review](09_ui-review.md)가 1차 점검 대장이었다면, 이 문서는 **상시 순회 루프**다.
> 회차마다 화면 **하나만** 잡고 끝까지(수정·검증·푸시) 간다.

## 루프 프로토콜 (1회차 = 화면 1개)

```
1. 커서   아래 "순회 커서"의 다음 화면 하나를 잡는다
2. 캡처   conda run -n penv3.13-video python packaging\capture-screens.py
          + 필요하면 좁은 창(1180px)·상호작용 상태를 별도 스크립트로 재현
3. 검토   기획자의 눈으로 — 아래 상용 기준 P1~P12 를 하나씩 소리 내어 대조
4. 수정   발견한 것을 그 자리에서 고친다 (기능 제거 금지 — 사용자 조건)
5. 검증   pytest 전체 + 재캡처 눈검수
6. 기록   아래 회차 기록에 한 줄 + 커서 전진
7. 푸시   커밋 → origin/master (사용자 상시 지시)
8. 재시작 떠 있는 앱 창을 새 코드로 재시작
```

**추정 금지 — 반드시 캡처를 눈으로 본다. 캡처 자체도 의심한다** (09 캡처 함정 표).
큰 설계 변경(구조 개편·기능 추가)은 루프에서 하지 않는다 — 10_ux-plan 에 제안으로 적고
사용자 결정을 받는다. 루프는 **다듬기**다.

## 상용 기준 (P-체크 — 이 세션에서 사용자가 실제로 지적한 패턴의 일반화)

| P12 | **낭비 공간이 없는가** — 큰 빈 영역·중복 표시 | 09 G3·G5 승계 |
| P13 | **배치가 창 크기에 맞는가** — 내용이 좌상단에 몰리고 우·하가 크게 비면 위반. 콘텐츠 최대폭을 정하고 남는 폭은 의도적으로 배분한다 | "화면 사이즈에 비해 배치도 안 맞는다" (위저드 실측) |
