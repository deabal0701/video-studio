# 03 — 화면 설계

> 화면 11종. 편집 3종(①③⑤)이 본체이고, 그중 ⑤ 대본 에디터가 가장 크다.
> 모든 검증은 **입력 시점**에 건다 — "조용히 망가지는" 결함을 폼에서 불가능하게 만드는 것이
> 이 앱의 1원칙 ([00_overview.md](00_overview.md) 문제 정의).

## 화면 지도 · 라우팅

```
/                     대시보드 (최근 작업·진행 중 빌드·바로가기)
/courses              강좌 목록
/courses/:cid         ├ ① 설정   ② 커리큘럼   ③ 브랜드 킷     (탭)
/episodes/:id         ├ ④ 구성표  ⑤ 대본  ⑥ 빌드·검수  ⑦ 배포  (탭)
/library              미디어 라이브러리 (B롤·BGM·사진·폰트)
/templates            도식 템플릿 갤러리
/jobs                 작업 큐 (전역)
/settings             로컬 설정 (엔진 경로·TTS 키·에이전트 키)
--- 상용 트랙 ---
/,/pricing,/login     랜딩·요금제·인증        /account  팀·사용량·결제
```

전역 요소: 상단 바(현재 빌드 잡 상태 칩 — 클릭 시 /jobs), 좌측 내비.
빌드 진행은 SSE 로 어느 화면에서든 상단 칩에 흐른다.

## 공통 시각 규칙 — 디자인 토큰 (D11, 2026-08-15)

정본 = `web/src/styles/tokens.css` (apple.com 실측 토큰). 화면 코드에 색·간격·라운드를
하드코딩하지 않는다 — Element Plus 변수는 `style.css` 에서 토큰으로 매핑만 한다.

- **골격**: 프로스트 상단 바(`.vs-header`) → `.vs-container`(최대 1200px·좌우 22px) 안에
  **제목(`.vs-page-title` 28px) → 설명(`.vs-page-desc`) → 필터/액션 → 본문** 순서 고정.
  주 액션은 화면 머리 우측(`.vs-page-head`) 한 곳에만.
- **간격**: 카드 간 20px(`.vs-card-grid` — auto-fill minmax 300px), 섹션 간 40px
  (`.vs-section-title` 이 위 여백을 소유), 블록 간 16px.
- **표면**: 카드·다이얼로그 18px 라운드, 입력 8px, 버튼·태그는 pill. 표·리스트는
  `.vs-panel`(흰 배경 + 구분선 + 옅은 그림자)로 감싼다.
- **텍스트 위계**: 본문 `#1d1d1f` → 보조 `.vs-ink-2` → 캡션 `.vs-ink-3`. slate-* 유틸 금지.

## ① 강좌 설정 — course.json 편집 폼

**목적**: 강좌 정체성을 한 번 정하고 고정. 스킬의 "강좌 개설 질문 4개"가 그대로 폼이 된다.

```
│ 태그라인  [개념 하나를, 5분에  ]  │  ← 값 바꾸면 즉시 재렌더      │
│ 대상      [textarea           ]  │  (iframe + params 주입)      │
│ ── 목소리 ──────────────────────│                              │
│ (•) 선희 +8%   ( ) 인준 +19%    │  ▶ 미리듣기 (실제 TTS 합성)   │
│ rate 고급 [    ] → 6.4자/초 표시 │                              │
│ ── 브랜드 ──────────────────────│                              │
│ brand [#F97316] soft[ ] bg[ ]   │                              │
│ ── 사운드 ──────────────────────│                              │
```

|---|---|
| 목소리 미리듣기 | `POST /api/tts/sample` — 고정 문장을 실제 합성해 재생 (edge 무료). rate 변경 시 재합성 + 초당 글자수 실측 표시 |
| 색 | 컬러 피커. 프리뷰 즉시 반영. **회차 클립 params 자동 주입의 원천** (⑤) |
| BGM | 라이브러리에서 선택 + 브라우저 재생. "자동 선택 금지 — 사람이 귀로 고른다" 규약을 UI 가 수행 |
| 저장 후 | 기존 회차들과 일관성 재검사 → 어긋난 회차에 배지 (②에 표시) |
| 잠금 | 목소리·태그라인은 회차 1개라도 ✅면 변경 시 경고 모달 ("시리즈 일관성이 깨집니다 — 기존 회차 재빌드 필요") |

## ② 커리큘럼 보드 — 회차 상태 칸반

```
⬜ 대기            🔄 제작 중              ✅ 완료
┌────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ 4강 발령    │   │ 2강 인사정보      │   │ 1강 구성원  4.2점 │
│ 근거: v0.09 │   │ 대본 87% · 추정4:5│   │ 4:56 · 16:9     │
│ [회차 생성]  │   │ ⚠ 예산 +12%      │   │ [재생] [배포탭]  │
└────────────┘   └─────────────────┘   └─────────────────┘
```

- 카드 = `course.episodes[]` + 파생 상태([02](02_data-model.md)). 드래그로 순서 변경(episodes 배열 재정렬).
- **[회차 생성]**: 폴더 생성 → episode.scenes.json 템플릿 복사 → course 의 voice/render/palette 주입
  → 골격 클립(broll·title·hook·stinger·promise·outro) 생성. 지금 수동으로 하는 스캐폴딩 전부.
- 배지: 예산 초과 · 일관성 어긋남 · 재빌드 필요 (파생 상태 그대로).
- "AI 초안" 버튼(4단계): 근거 문서를 주면 에이전트가 plan.md+scenes.json 초안 생성 ([05](05_agent.md)).

## ③ 브랜드 킷 — 타이틀 카드·스팅어 커스터마이즈

**목적**: course-intro/stinger html 을 **코드 없이** 조정. 상용에서 "내 강좌처럼 보이게"가 상품가치.

- 프리셋 갤러리(1단계는 기본 1종) → 선택 시 강좌 폴더로 카피.
- 조정 슬롯: 색(palette 연동)·글꼴·shade. html 직접 편집은 "고급" 접힘 뒤에.
- 프리뷰: 실제 params(1강 제목 등)를 넣은 상태로 렌더 + **3초 재생** (스팅어는 시간 연출이 본질).
- 일관성 규약 노출: "스팅어는 회차마다 동일해야 합니다" — 회차별 편집 진입점을 두지 않는다.

## ⑤ 대본 에디터 — 앱의 본체

**목적**: scenes.json 의 `motion.clips[]` 를 구조화 편집. 경로·params·분량 결함을 입력 시점에 차단.

```
┌ 클립 리스트 ──┬─ 클립 편집 ────────────────────────┬─ 프리뷰 ──────┐
│ ≡ broll  2.0s │ id [hook]        내레이션 57자/8.9s │               │
│ ≡ title  4.0s │ ┌ 화면 ─────────────────────────┐  │  [iframe:     │
│ ≡ hook   8.9s │ │(•)도식 [hook-bill.html ▾][🔍] │  │   hook-bill   │
│ ≡ stinger3.0s │ │( )B롤  [피커…]  ( )없음        │  │   params 주입  │
│ ≡ promise ... │ └───────────────────────────────┘  │   재생/스크럽] │
│ ≡ ch1    ... │ 내레이션                            │               │
│ ≡ s1a  ⚠253 │ [이 사람은 아직 출근하지 않았습…]     │  ▶ 음성 듣기   │
│   …          │ ── params (템플릿이 받는 키만) ──    │  (TTS 캐시    │
│ + 클립 추가   │ t1 [4.5] t2 [7.2]  [발화시각 계산]  │   있으면)     │
│──────────────│ shade [0.35] wipe [off ▾]          │               │
│ 합계 2,074자  │ brand·bg·font ← 강좌 자동 주입 ✓    │               │
│ ⚠ 예산 +12%  │ 고급 ▸ (duration·before·videoStart) │               │
└──────────────┴────────────────────────────────────┴───────────────┘
```

**클립 리스트 (좌)**
- 드래그 정렬 = 배열 순서. 골격 위치 규약(broll→title→hook→stinger→promise) 위반 시 경고.
- 클립별 길이: TTS 캐시 있으면 실측, 없으면 추정 (라벨 구분). 하단에 예산 게이지 상시.
- [+ 클립 추가]: 종류 선택(챕터 카드/도식/B롤) → 골격 관례로 id 자동 제안.

**클립 편집 (중) — 결함 차단 4종이 여기서 일어난다**
| 결함 (현재는 조용히 발생) | 차단 방법 |
|---|---|
| 오타 params → 글자가 화면에서 사라짐 | 템플릿 선택 시 `inspect.js templateKeys` 로 **받는 키만 폼 생성.** 자유 키 입력 자체가 없음 |
| 상대경로 오류 → 검은 화면·검은 배경 | 파일 피커로만 선택. 경로는 `core/paths.py` 가 기입 ([02](02_data-model.md) 표 5행) |
| 브랜드 색·폰트 누락 | course.palette 자동 주입 (수동 입력 불가, "상속 중" 뱃지만) |
| B롤 길이 초과 → 정지 프레임 | 피커가 소재 길이를 알므로 `duration > 소스−videoStart` 즉시 빨강 |

- **발화시각 계산기**: 내레이션에서 구절을 드래그하면 시작 시각(글자수÷페이스)을 계산해
  `t1`·`t2` params 에 꽂아 준다 — "도식 등장 시각 = 발화 시각" 규약의 도구화.
- title 클립 특수 처리: B롤 프레임 추출(`videoStart` 시각) → bg/ 저장 → `params.src` 자동 기입.
  현재 스킬이 "둘 다 조용히 망가진다"고 경고하는 videoStart↔프레임 일치를 **한 버튼**으로.

**프리뷰 (우)**
- 도식: iframe 에 params 주입 렌더 (`engine/preview.js`). 시간 스크럽 슬라이더(CSS 애니메이션이라
  `document.getAnimations()` 시킹으로 재현 — 엔진 렌더 방식과 동일하니 결과가 곧 실물).
- B롤: `<video>` 구간 재생. 음성: TTS 캐시 재생 + [이 클립만 TTS 갱신] (무료·몇 초).

**저장**: If-Match(mtime) · `_` 주석 보존 · 저장 시 일관성 대조 + 사전점검(빠른 부분) 자동 실행.

```
            로그 스트림 (SSE) ▾
[검수]      ┌ 프레임 그리드 ─────────────────────────────┐
            │ [밝은@0:12] [어두운@2:04] [타이틀@0:03] [마지막@4:52] │
            │ 각 장: 워터마크 확인 ☐ · 자막 겹침 확인 ☐      │
            └──────────────────────────────────────────┘
            무음 리포트: 문장 호흡 12건 (BGM 0.08 덮음 — 정상)
            자막 대조: .srt ↔ 대본 diff 0건 ✓
            일관성: 직전 회차 타이틀 프레임 나란히 [보기]
[평가]      점수 4.2/5 · 고칠 것 2건 [상세]     [재채점 1회]
```

- 빌드 버튼은 **잡 큐 제출** ([04](04_api.md)). `--only tts/compose` 부분 빌드 버튼 별도
  (재촬영 없는 수정 루프 — 스킬의 핵심 시간 절약).
- 프레임 그리드: 스킬 검증 규약의 4종(밝은/어두운/모션/마지막)+타이틀을 **자동 추출.**
  체크박스가 "봤다"의 기록으로 남는다 (검수 이력 파일).
- 무음 리포트: silencedetect 결과를 스킬의 원인 분류(클립 끝 몰림=duration 결함 vs 균일=TTS 호흡)
  로 자동 분류해 처방 표시.
- 평가: 에이전트 잡 (4단계). 점수·지적을 그대로 노출 — "낮은 점수를 감추지 않는다".

## ⑦ 배포 산출물

youtube.md 를 수동 작성에서 자동 생성으로. 제목(`[강좌명] n강 — 제목`)·설명(요약+챕터+재생목록
자리)·챕터(chapters.js — 실측 기반)·srt 다운로드·썸네일 후보(타이틀 카드 프레임 + 훅 절정 프레임).
전 항목 편집 가능 + 복사 버튼. 회차 ✅ 전환은 여기서 (평가 완료 조건).

## 미디어 라이브러리 / 템플릿 갤러리 / 작업 큐

| 화면 | 내용 |
|---|---|
| 라이브러리 | B롤·BGM·사진·폰트. **라이선스 필드 필수**(출처 URL·라이선스 종류 — CATALOG.md 규약의 DB화). URL 로 가져오기(fetch.js 의 허용 호스트 검증 유지). B롤은 길이·해상도 자동 추출, 미리보기. "가운데가 비었는가" 판단용 그리드 오버레이 |

| 작업 큐 | 전역 잡 목록 (대기/실행/완료/실패) · 진행 스트림 · 실패 로그 · 재시도. 동시성 정책 표시 ([04](04_api.md)) |
