## 왜 다시 만드는가

`video-studio-guide`(2026-08-22, 7분 55초, 평가 3.3)의 후속이다. 사용자 요청 세 가지:

1. **화면이 많이 바뀌었다** — 그 뒤로 품질 루프가 35회차까지 돌았고, 좌측 열이
   `[새 영상 만들기]` 버튼 + 화면 4개로 재편됐다. 옛 영상의 캡처는 전부 낡았다.
2. **대본 작성이 어렵다** — 옛 영상은 "② 대본 탭이 있다"까지만 말했다. 이번엔
   **대본을 어떻게 쓰는지**가 한 부(2부)를 통째로 차지한다.
3. **내부적으로 어떻게 만들어지는지** 상황별로 — Playwright · 프레임 연동 ·
   내가 넣은 이미지 · 참조. 3부가 이것이다.

## 뼈대 — 3부 구성

```
도입      이 앱이 하는 일 + 전체 지도
1부       사용법        화면 순서대로 (앱이 붙인 번호가 곧 목차)
2부       대본 작성법   클립이란 무엇인가 → 세 가지 시작법 → 분량 → 앱이 막아 주는 것
3부       내부 동작     [빌드]를 누르면 무슨 일이 일어나는가
마무리    회수
```

**1부의 구조는 지어내지 않는다** — 앱이 화면에 번호를 달아 놓았고 그 번호가 곧 순서다.

```
프로젝트    [영상 목록] [설정] [브랜드 킷]      ← 번호 없음 (순서가 아니라 서랍)
└─ 영상     ① 구성표 ② 대본 ③ 검수 ④ 배포     ← 번호는 여기만 (진짜 순서)
```

**3부의 눈높이는 "담당자"다**(사용자 지정). 파일명·JSON 필드를 읽어 주지 않고 도식과
비유로 원리만 말한다. 단, 화면에는 실제 이름이 보이므로 궁금한 사람은 눈으로 가져간다.

## 소재 — 실화면 + 도식, B롤 없음

**이 앱은 Qt 데스크톱이라 Playwright 로 녹화할 수 없다.** 저장소 정본 캡처
(`packaging/capture-screens.py` → `docs/ui-shots/` 16장)를 쓴다.

> 이 사실 자체가 3부의 소재다 — "웹앱이면 Playwright 가 조작하며 녹화하고, 데스크톱
> 앱이면 캡처를 넣는다"가 상황별 설명의 한 축이 된다.

**굽기 전에 얼려 놓고 굽는다 — 이 영상의 1원칙이다.** 옛 영상은 렌더 도중(20:20~20:57)
다른 세션이 캡처를 다시 찍는 바람에 **옛 화면과 새 화면이 한 영상에 섞였다**. 지금도
다른 세션이 품질 루프를 돌고 있으므로 같은 사고가 재현될 수 있다.

- `shots/` 에 16장을 복사해 두고 대본은 **그쪽만** 가리킨다 (`docs/ui-shots/` 를 직접 안 본다)

## 걸린 것 (굽기 전에 잡은 것들)

**1. `baseUrl` 이 없어 엔진이 즉시 죽었다.** `scenes` 가 비어 촬영이 없어도
`build.js` 48행이 `config.baseUrl.replace()` 를 무조건 부른다. 포트 0 을 관용 표기로 넣었다.

**2. 모든 클립에 `before: "end"` 가 필요했다 — 이번 제작에서 제일 큰 사고.**
`compose.js`(340·345행)는 모션 클립을 **`before` 값으로만** 타임라인에 놓는다.
씬이 있으면 `before: <씬id>`, 없으면 `before: "end"`. 그런데 나는 `outro` 에만 달았다.
결과: **40클립 중 1개만 합성되어 4.67초짜리 mp4 가 나왔는데 빌드는 "완료"를 찍고 exit 0**.
자막도 111바이트였다. `ffprobe` 로 재 보기 전에는 성공으로 보인다.
→ 40클립 전부에 달았다. `_배치메모` 로 대본에 이유를 남겼다.

**3. 도식 등장 시각이 내레이션보다 20초 이상 빨랐다.** CSS 에 지연을 박아 두었더니
`d-audio` 가 "249장"을 4초에 다 보여 주는데 말은 21.6초에 그 얘기를 했다. 그림이 결론을
미리 뱉으면 설명이 죽는다. → **등장 시각을 대본이 넘기도록** 9장 전부 고치고(`t1`·`t2`…),
실측 음성 길이에서 문장별 발화 시각을 역산해 값을 넣었다.

**4. 프로토 렌더에서 "말한 것이 크롭 밖" 3건.** 어제 평가가 지적한 것과 같은 유형이다.

- `plan2` — "구간·화면·글자수 **세 칸**"이라 했는데 글자수 열은 표 오른쪽 끝이라 크롭 밖.
  → "왼쪽은 구간, 오른쪽은 화면"으로 (보이는 대로).

**6. `pick` 이 없는 단추를 가리킬 뻔했다.** 06 캡처는 도식 클립이라 `[B롤 선택…]` 이 없다.
