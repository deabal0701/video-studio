## 제작

담당자가 앱을 처음 켰을 때 "다음에 뭘 해야 하는지"를 화면 순서대로 알려 주는 매뉴얼 영상.
사용자 요청은 "자세히, 화면을 캡처해서 각각 설명"이었다.

**구조를 지어내지 않았다.** 이 앱은 화면에 번호를 직접 달아 놓았고(① 설정 … ⑦ 배포) 그 번호가
곧 작업 순서다. 그래서 목차를 새로 만들 필요가 없었고, 도입에 지도 한 장을 깔고 번호를
실화면으로 하나씩 짚은 뒤 같은 지도로 회수하는 구성이 됐다. 초보자가 제일 헷갈리는 지점이
**①②③은 프로젝트에 한 번, ④⑤⑥⑦은 영상마다 반복**이라는 층 구분이라, 도식(`flow7.html`)이
그 두 층을 두 개의 상자로 그린다.

**캡처 도구를 새로 만들지 않았다.** 처음엔 `capture_shots.py`·`capture_live.py` 를 새로 썼는데,
저장소에 이미 `packaging/capture-screens.py` → `docs/ui-shots/` 16장이 있었다(09_ui-review 의
점검 루프가 쓰는 정본). 새로 만든 둘을 지우고 정본을 쓴다 — **화면이 바뀌면 그 루프가 같은
파일을 덮어쓰므로 이 영상의 소재도 자동으로 최신이 된다.** 병렬 캡처 폴더를 두면 갈라진다.

**전용 템플릿 두 장을 새로 그렸다.**

| 파일 | 왜 |
|---|---|
| `appshot.html` | 앱 화면 PNG 에 크롭·강조·느린 밀어들어가기. **크롭이 핵심** — 1600×1000 창을 통째로 1080p 에 넣으면 14px 글자가 안 읽힌다. 강조는 상자 밖을 거대한 spread 그림자로 덮어 "여기를 보라"를 말이 아니라 그림으로 한다 |
| `flow7.html` | ①~⑦ 화면 지도. 글자 카드로 때우면 구조가 안 보이는 자리 |

목소리·BGM·범위는 착수 전 한 라운드로 물었다(선희 edge · BGM 0.08 · 화면별 상세).
BGM 을 깐 이유는 09/스킬의 실측 근거 — BGM 이 없으면 TTS 문장 호흡(1.2~1.4초)이 전부 무음으로
노출된다.

## 걸린 것

**1. 사전 점검이 내 템플릿의 params 를 전부 오탐할 뻔했다.**
0단계 점검은 템플릿이 받는 이름을 `data-p="…"` 와 **리터럴 `.get('키')`** 로만 찾는다.
`num(k, d)` 안에서 `q.get(k)` 로 읽거나 `` q.get(`t${n}`) `` 로 조립하면 그 이름을 못 본다.
→ 두 템플릿 모두 키를 리터럴로 한 번씩 적는 방식으로 바꿨다(`const P = { cx: q.get('cx'), … }`).
이건 코드이자 "이 템플릿이 받는 params" 선언이 된다.

**2. 크롭을 줘도 확대가 안 됐다.** `ch` 기본값을 100 으로 둬서
`z = min(100/cw, 100/ch)` 가 `min(1.43, 1)` = 1 이 됐다. 배율은 죽고 translate 만 남아
이미지가 옆으로 밀리며 오른쪽에 검은 띠가 생겼다. → `ch` 기본값을 `cw` 로.

**3. 강조 상자가 엉뚱한 곳을 가리켰다.** 틀을 91.6vw×70vh(2.33:1)로 잡았더니 `object-fit: cover`
가 세로를 23% 잘라내, **원본 45% 지점이 화면 58% 에** 찍혔다. → 틀을 16:9 로 바꿨다
(72vw×72vh). 16:9 프레임에서 **높이 H vh 인 상자의 16:9 폭은 정확히 H vw** 다. 그래야 %
좌표가 원본 PNG 와 1:1 로 맞는다. 세로형 대화상자는 `fw = 비율 × 40.5` 로 준다.

**2·3 은 굽기 전 프로토 렌더(Playwright 로 템플릿 7장을 한 프레임씩)에서 잡았다.** 둘 다
"합성은 성공하는데 화면이 틀린" 종류라 굽고 나서야 드러났을 것이다. 프로토 렌더 비용은 10초,
전체 빌드는 수십 분이다.

**4. 사전 점검이 `outro` 의 `wipe` 켜짐을 잡았다** — 모션 전용 영상이라 흰 점멸이 남을 뻔했다.

**5. 앱 결함 8건이 따라 나왔다.** 화면을 고치려고 본 게 아니라 **남에게 설명하려고** 봤더니
"이 칸이 왜 비어 있죠?"에 답을 못 하는 자리가 나왔다. 전부
[09_ui-review 의 "미해결" 표](../../docs/design/09_ui-review.md)에 F1~F8 로 기록했다.
그중 F1(강좌 공용 템플릿 프리뷰가 안 뜸)은 `template_preview` 를 직접 호출해 재현했다 —
15개 클립 중 13개 OK, `../hr-basics/course-intro.html`·`course-stinger.html` 만 `NotFound`.
