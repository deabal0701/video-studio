## 구간 배분

**화면 칸을 먼저 채운다.** 기술 설명 구간에 `stat`(글자 카드)이 연달아 있으면 그 자리는
설명이 비어 있는 것이다 — 도식을 그린다. B롤 구간은 **소재 길이 안에** 글자수를 맞춘다.

| 구간 id | 무엇을 말하나 | 화면 | 글자수 | 소재 길이 | 비고 |
|---|---|---|---|---|---|
| intro | | `intro.html` | | — | |
| ch1 | | `chapter.html` | | — | |
| b1 | | B롤 `<파일>` | | `<ffprobe 실측>s` | 글자수 ≤ (길이−videoStart)×6.3 |
| s1 | | **도식** `<파일>` | | — | 무엇을 그림으로 보이나: |
| outro | | `outro.html` | | — | |
| | | | **합계 <N>자** | | 예산과 맞는가? |

## 도식으로 만들 것

구조·흐름·비교·시간에 따른 변화를 말하는 구간이다. 글자 카드로 두면 안 되는 자리.

| 구간 | 그림이 져야 할 설명 | 쓸 템플릿 |
|---|---|---|
| | | 기존(`cloud-*`)을 문구만 바꿔 쓰나, 새로 그리나 |

## 확인한 것

- [ ] B롤 길이를 `ffprobe`로 **실제로 쟀다** (짐작 금지)
- [ ] 쓰려는 템플릿의 params 이름을 `grep -o 'data-p="[a-zA-Z]*"' <파일>`로 확인했다
- [ ] 내레이션에 넣을 수치의 **출처가 저장소에 있다** (없으면 빼거나 비수치 표현으로)
- [ ] 소재 라이선스를 `assets/CATALOG.md`에서 확인했다
